# 解析内容与可追溯性

共用前置条件：使用隔离实例和预标样本；上传并等待任务结束，下载完整结果和相关产物，在原件阅读器中逐项对照。每条保留输入 SHA、任务 ID、结果片段与必要截图。任务 succeeded 对应结果 completed；partial 不是完整成功。不要把任务状态和结果状态字段混为一谈。

## 文本与 JSON

- [ ] **TXT-01 / P1 / 原文保真**。准备含 BOM、中文、emoji、CRLF、空行、代码围栏和重复段落的 UTF-8 文本。操作：解析后逐段比较首尾和重复次数，并下载原件。预期：正文不被摘要、翻译、去重或改写；BOM 处理和字符偏移符合 [结果契约](../../contracts/v0.2.0-draft.1/README.md)，原件字节摘要不变。证据：至少首段、中段、末段的原文/结果对照。
- [ ] **TXT-02 / P0 / 字符定位**。在上一样本选择中文、emoji 后的一段文字，用结果 TextSpan 在原文字符序列中切片。预期：切片与证据完全一致，不把 UTF-8 字节数当字符数，不越界；记录起止值与切片结果。
- [ ] **TXT-03 / P1 / 非法输入**。分别提交非法 UTF-8、空文件、只有空白的文件。预期：非法编码和空输入不伪装成有内容的 completed；空白文件按现有契约明确处理、不编造段落。分别记录接入拒绝或任务失败阶段及代码，不能只记录“失败了”。
- [ ] **JSON-01 / P0 / 类型保真**。准备包含 false、0、null、"00123"、空数组、空对象、中文键和深层数组的 JSON。预期：下载结果中的类型与原件一致；false 不变 0，数字字符串不转数值，null 不变空串。证据：逐项类型/值对照。
- [ ] **JSON-02 / P0 / 特殊键指针**。使用含 `/`、`~`、空键和数组索引的嵌套对象。操作：对每个目标沿 JSON Pointer 回查原件。预期：转义及数组位置正确，值相等且类型相同；记录至少 5 个指针与目标。
- [ ] **JSON-03 / P1 / 不合法与限额**。分别准备重复键、截断 JSON、NaN/Infinity、嵌套深度超过 64 的文件。预期：拒绝或失败且解释原因，无悄悄覆盖键、接受非标准值或卡死。临界深度通过与否按实际计数规则核对，超过上限必须有界停止。

## Word

- [ ] **DOC-01 / P1 / 中文正文结构**。用至少 3 份不同来源 DOCX，含多级标题、列表、超链接文本和相同段落。预期：正文首尾和中间抽查点均存在，重复不丢，列表/标题角色可解释；不承诺与 Word 排版分页相同。记录每份至少 10 个检查点和漏失明细。
- [ ] **DOC-02 / P0 / 合并表格**。准备横向、纵向合并及表中空白单元格，提前标注行列和跨度。预期：内容归属与跨度对应，非合并单元格不串位，不能靠重复填值掩盖合并关系。证据：原表截图及完整 table data。
- [ ] **DOC-03 / P1 / 页眉脚注与修订**。用多节页眉页脚、脚注、插入/删除修订样本。预期：核对可提取内容及角色；当前最终文字视图应保留插入文字、不当作修订审计历史。不能宣称有精确脚注正文链接。记录每项实际保留、缺失和问题提示；复杂变体转 UNC-01。
- [ ] **DOC-04 / P0 / 派生定位与图片**。选择正文、表格、图片各一块，下载完整 Docling JSON 和图片。预期：document_node 指针确实能回查对应内容，精度为 derived_exact；不伪造 Word 页码/XML 节点精确性。图片可打开、来源绑定正确；记录 artifact ID/摘要和指针。

## PowerPoint

- [ ] **PPT-01 / P1 / 页归属与备注**。用至少 3 份含相同文字、分组文本、演讲备注的 PPTX。预期：各页正文不串页，重复保留，备注有独立角色及幻灯片关联；不把演讲备注混称为屏幕正文。逐页抽查并记录全部遗漏。
- [ ] **PPT-02 / P0 / 表格和原生图表**。准备合并表与有正负数/小数/多系列的原生柱状图，提前记录类别和数值。预期：已支持图表的 table/native_chart 保留上游类别、系列与值；未渲染给出 warning，不声称视觉理解。未支持图表类型转 UNC-02，不能以空结果算通过。
- [ ] **PPT-03 / P0 / 定位边界**。挑不同幻灯片的文本/表/图块回查上游 JSON。预期：指针可解析且对应正确；不声称原始 shape ID 或精确形状定位，不将 EMU 作为 PDF pt。证据：三类块的定位/原始节点对照。

## Excel

- [ ] **XLS-01 / P0 / 表与地址对应**。准备空白首表、图表页插在数据表之前、中文表名、多块区域。预期：真实数据仍属于正确工作表，A1 地址吻合；图表重构数据不伪造 sheet_range。记录至少 10 个跨表单元格及两块区域的位置。
- [ ] **XLS-02 / P0 / 值与类型**。对照 0、false、错误值、前导零字符串、日期、超过 24 小时时长和空单元格。预期：原始类型、值和数字格式被区分，不用显示文本覆盖原始证据；49.5 小时不变成仅 1.5 小时。保留原件显示与结果字段对照。
- [ ] **XLS-03 / P0 / 公式和缓存**。准备有缓存、无缓存、区域外公式和仅公式工作簿。预期：公式原文与缓存分开；无缓存为缺失而非 0；不计算公式、不执行外部引用。将源公式逐一对照，不以 Excel 打开后重算的值冒充输入文件原有缓存。
- [ ] **XLS-04 / P1 / 合并隐藏和批注**。准备二维合并、隐藏行/分组列、veryHidden 工作表和原生批注。预期：真实单元格与合并范围、隐藏状态、可获取批注正确保留；隐藏不等于删除。记录原件设置和输出路径。
- [ ] **XLS-05 / P1 / 明确拒绝**。使用数组/数据表公式样本及检查区域超过 100000 单元格样本。预期：当前不支持公式明确拒绝，超预算有界失败；不宣称已计算或正确解析，不拖住后续小任务。动态数组、透视表另见 UNC-03。

## PDF

- [ ] **PDF-01 / P1 / 原生中文**。用至少 2 份不同生成工具的原生中文 PDF，核对中文、标点、数字、换页与重复文字。预期：正确保留可解码原生文本和页归属，不以英文正常替代中文验证；缺字/乱码必须记录。证据：每页关键文本及完整提取片段。
- [ ] **PDF-02 / P0 / 坐标和旋转**。选至少 5 个文本块，包含 90 度旋转页及非首页。操作：按契约坐标原点/单位/页面旋转规则在阅读器对照区域。预期：页码和区域正确、框在页面内，单位 pt；不把旋转前后坐标直接混用。保留页面尺寸、框值和标注截图。
- [ ] **PDF-03 / P0 / 多列与表格边界**。解析多列中文、复杂表格 PDF。预期：不宣称已恢复阅读顺序、标题层级或表格结构；阅读顺序保持 unresolved。即便状态 completed，也只表示 native_extract 目标，不表示语义版面重建完成。记录观察到的顺序与边界声明。
- [ ] **PDF-04 / P0 / 扫描和混合页**。分别解析纯图片、原生页眉+扫描正文、文字+装饰图片 PDF。预期：含位图页保守报告 external_ocr_required 与 coverage 缺口，保留可用文本/图片并返回 partial；装饰图也可能触发，这是当前限制。不能把页眉存在当整页已读，不发生本地 OCR 或外部自动调用。
- [ ] **PDF-05 / P1 / 损坏及空白**。分别提交截断 PDF、没有原生文本的页面、真实视觉空白页。预期：损坏不成功；无原生内容不能直接宣称视觉空页。记录页覆盖与问题，复杂加密/裁切/字体变体另见 UNC-04。

## 跨格式共同要求

- [ ] **EVD-01 / P0 / 原件与产物一致**。每类至少一份，从 UI/API 下载原件并计算 SHA256，核对 Source；每个下载产物核对摘要/字节数。预期：与输入和 Artifact 元数据一致，无错绑、截断、用其他任务产物替换。
- [ ] **EVD-02 / P0 / 缺口与结果状态**。对完成、部分完成、失败各选一份，比对任务、结果、coverage、issues、UI。预期：各层一致；正文遗漏不能因进程退出 0 而消失；partial 已保留证据仍可取，失败无伪造成功内容。保存完整响应而非只截状态徽标。
- [ ] **EVD-03 / P1 / 重复与独立性**。同一文件重复解析，再解析同名不同内容文件。预期：可解释内容一致；不同字节不串结果，来源摘要及任务关联正确。不要要求随机 ID、时间戳字节一致，也不要把同名当同一来源版本。
