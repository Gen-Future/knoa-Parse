# 独立文本模型、渠道与私密配置

前置：独立 provider 配置文件、隔离实例。密钥只进私密文件或输入框，截图/日志必须脱敏。协议错误优先用本地合成传输或隔离模拟 Provider；真实平台仅执行专门连通性用例。记录是否真实调用和供应商报告用量，不推算费用或代金券。

- [ ] **MOD-01 / P1 / 未配置**。无 provider 文件且无模型环境变量启动，打开模型设置并尝试独立生成。预期：明确未配置，不显示虚假可用；原生六格式按依赖能力继续运行，无自动回退到本地模型。保存能力响应及 TXT 结果。
- [ ] **MOD-02 / P1 / 保存与即时生效**。在隔离配置中选择自定义 OpenAI 协议，填写 HTTPS 根地址、模型、密钥、超时；保存后刷新，再由独立 CLI 读取。预期：当前单 API 进程立即生效，新 CLI 读到同样配置；页面不回显密钥，只显示已配置状态。证明落盘成功而非仅表单改变。
- [ ] **MOD-03 / P0 / 换渠道不复用旧凭据**。同平台/协议/地址留空 key 保存，再分别改变地址、平台、协议而不填新 key。预期：同渠道空白保留已有 key；改变渠道必须新 key，旧凭据不发给新地址。用合成 key 和可检查请求的隔离传输验证，不能把真实 key 发到测试站。
- [ ] **MOD-04 / P1 / Anthropic 映射**。切到自定义 Anthropic、清除不适用的 thinking 配置，使用合成 Messages 响应。预期：请求路径/头/system 正确，多个 text 块合并，停止原因及用量按协议映射；max_tokens/tool_use/refusal 不冒充完整答案。真实账户兼容性另记 UNC-08。
- [ ] **MOD-05 / P1 / 未保存与真实连接**。修改字段但不保存时尝试“测试已保存配置”；保存后人工点击一次测试。预期：未保存时不能误测新表单；仅一次真实调用，固定合成提示、最多 16 输出 tokens，显示真实响应/模型/供应商报告用量，无自动重试。该步骤会用平台额度，单独记录测试账户与时间，不记录 key。
- [ ] **MOD-06 / P0 / 密钥不泄露**。以独特合成 key 保存，检查 GET settings、capabilities、成功/错误响应、浏览器 URL/localStorage/sessionStorage、控制台和后端日志。提交字段校验错误再检查。预期：无明文 key 回显或持久浏览器存储，错误不回显请求凭据。配置文件里存在 key 是预期，不复制其内容到证据。
- [ ] **MOD-07 / P1 / 环境覆盖**。仅在隔离进程设置模型环境变量，打开设置，再移除覆盖重启。预期：覆盖期间界面只读并说明来源，不能保存后误以为生效；撤销覆盖后恢复文件配置。记录变量名称和生效字段，不记录密钥值。
- [ ] **MOD-08 / P0 / 写入失败原子性**。用隔离配置路径模拟不可写/替换失败，再保存。预期：清楚失败，旧配置和当前适配器保持可用，不出现半份 JSON 或 UI 假成功；修复权限后可重试。Windows 下无法稳定模拟权限时使用合成故障注入并说明，不改真实配置权限。
- [ ] **MOD-09 / P0 / 外部失败与有界请求**。用合成响应分别模拟 401/402/403/404/429/5xx、超时、非法 JSON、超大响应、缺少文本、重定向。预期：错误代码稳定且脱敏，retryable 语义正确，只有一次请求，不跟随重定向转发凭据；超时不承诺远端未计费。保存脱敏请求计数和响应，不能用一次断网替代全部故障。
- [ ] **MOD-10 / P1 / 输入与生成边界**。提交空/过长 prompt、过长 system、max_tokens 越界、超过 192 KiB 请求和未允许字段；CLI 用超过 128000 字节文本。预期：在请求平台前明确拒绝，无偷偷截断后计费。有效响应标记 inferred，不写 ParseResult，不自动创建解析任务或当作原文证据。
- [ ] **MOD-11 / P0 / 原生解析离线独立**。配置可追踪的合成 Provider 后解析六类样本，再在断网条件下重复原生解析。预期：没有 Provider 调用、权重下载或推理模块加载；仅独立文本模型操作能访问平台。浏览器自身轮询不算解析联网，需区分 worker 子进程与 UI/API 请求。
- [ ] **MOD-12 / P1 / 私密路径与重启**。指定不存在/损坏的显式 provider/server 配置路径；另正常直接编辑隔离 provider 文件后比较重启前后 API 与新 CLI。预期：显式错误路径安全失败，不静默换平台；直接改文件的 API 需重启、CLI 下次调用读取，工作台保存仅当前单进程即时更新。不宣称多 API 进程自动同步。
