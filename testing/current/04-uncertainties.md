# 开发后不确定项与探索验收

这份清单是已有工程的开发后补建记录，覆盖真实资料、上游结构、实际环境与 UI/模型链路。关联目标见 [本轮基线](00-scope-and-preparation.md)，常规用例见同目录 01–03。初始全部未执行；历史合成/单元测试不能消除这些不确定性。

处置只可选：修复并复验、保留明确限制、拆成后续任务、因条件不足阻塞。结论记录关联用例/样本/问题编号；选择延期不能写成通过。每项负责人当前均待分配。

- [ ] **UNC-01 / P1 / 复杂 Word**。不确定：不同作者工具的文本框、嵌套表格、批注、脚注关联、复杂修订/命名空间是否丢失。准备至少 3 个含这些特性的真实去敏 DOCX；先标注正文和附属内容，再与完整上游树及结果比较，区分上游丢失与适配遗漏。判断：常见正文漏失或静默错绑须修复；未支持结构须描述范围，不能称 DOCX 全特性支持。关联 DOC-01～04。
- [ ] **UNC-02 / P2 / 复杂幻灯片**。不确定：SmartArt、深层分组、任意图表、动画及阅读顺序。用含这些对象的原生 PPTX，逐页记录对象数、可见文字和图表值；比较上游树/最终证据。判断：已支持路径不丢，未覆盖对象有明确限制；不把图像存在视作图中内容已理解。关联 PPT-01～03。
- [ ] **UNC-03 / P1 / 复杂 Excel**。不确定：动态数组、透视表、外链、线程批注、嵌入图形以及不同软件生成的公式缓存。用去敏工作簿先检查原始文件状态，再打开阅读器避免重算污染输入；解析逐项核对。判断：不执行外链、不计算公式，不支持结构不能编造值或 A1。分别记录拒绝、缺口和静默遗漏。关联 XLS-01～05。
- [ ] **UNC-04 / P1 / 真实 PDF 变体**。不确定：复杂字体、加密/口令、裁切/任意角度旋转、矢量图、真实扫描覆盖。分别准备这些变体，逐页标记视觉内容与原生层；核对文字、坐标、图片和覆盖。判断：结果不夸大理解程度，不能以“没有位图”证明文字完整；矢量正文可能遗漏需单独记录。OCR 准确率不在本轮。关联 PDF-01～05。
- [ ] **UNC-05 / P1 / 大资料与冷启动**。不确定：小合成样本之外的等待时间、峰值内存和界面响应。每类选择小/中/接近预算 3 档，记录大小、页/单元格数、冷启动和连续 3 次运行的墙钟时间/峰值内存；保留系统配置与并发条件。判断：有界结束、无 UI 卡死或子进程残留；未定义性能 SLO 时只报告观察，不事后拿最慢值当验收阈值。后续设 SLO 必须先定义再测。
- [ ] **UNC-06 / P1 / 硬中断与存储寿命**。不确定：worker/API 强杀、掉电近似中断、磁盘满后恢复、孤儿产物和长期运行。隔离数据中分 queued/running/提交结果阶段强停，重启观察租约与文件；用受控故障模拟磁盘写失败。判断：不损坏已发布结果，不谎报成功；恢复机制、人工步骤和遗留文件明确。逐单元恢复、迁移、GC/保留策略尚未实现，不能假定自动修复。关联 RUN-04/05/08。
- [ ] **UNC-07 / P1 / 跨环境与打包**。不确定：本轮更改后 Linux/macOS、Python 3.11/3.12、干净 wheel 安装和非管理员 Windows。分别在可获得环境跑同一自动检查与六格式最小人工链路，安装 wheel 后从仓库外目录启动 API/console。判断：能力、中文路径、静态资源、取消与预算行为符合平台声明；缺少设备记阻塞，Windows 结果不能代替其他系统。
- [ ] **UNC-08 / P1 / 真实模型平台兼容性**。不确定：不同平台的协议扩展、thinking、额度/限流与 Anthropic 真实响应。仅在测试账户下用固定无敏感合成提示逐平台执行一次，记录请求时间、协议、模型、响应和用量，必要时查脱敏错误。判断：不凭 OpenAI 合成通过宣称所有平台可用；当前 Anthropic 真实账户未验收，费用/券抵扣不能从 token 数推断。关联 MOD-04/05/09。
- [ ] **UNC-09 / P1 / 人工体验与可访问性**。不确定：真实长文件名/长表、低分辨率、屏幕阅读器、键盘和不同浏览器。让未参与开发的人从空实例完成上传→找到缺口→定位原文→下载；记录卡点和错误理解，再测真实浏览器缩放/读屏。判断：用户能分辨完整/部分结果和派生定位；自动 DOM 测试与截图不能代替此项。关联 UI-05～08。
- [ ] **UNC-10 / P0 / 依赖及执行边界**。不确定：新安装路径、上游升级或特殊文件触发隐式联网/进程。使用干净模型缓存及受控网络/进程观察，跑六格式和异常样本，核对锁/实际依赖审计、加载模块与被阻止调用。判断：无本地推理/权重下载、无未解释的网络/后代进程；Python 审计和 Windows 直接杀子进程不等于完整 OS 沙箱。任何违背模型边界的行为阻断接入。关联 MOD-11。
- [ ] **UNC-11 / P1 / Demo 使用范围**。当前免鉴权只用于本地单用户。核对启动参数为回环地址、文档/UI 没有多租户或生产安全承诺；验证无需 token 是预期。判断：不以本轮验收支持公网部署；若需求扩展到远程访问/多人，先定义独立鉴权、隔离、凭据写入与攻击面验收，再实施。此项不要求擅自恢复登录。
- [ ] **UNC-12 / P1 / 主仓消费契约**。主仓目前是旧版快照，本轮不验证完整记忆产品。对照 Parse 输出版本与主仓 manifest，记录显式迁移待办和所需转换/绑定校验。判断：不把 Parse UI 成功当主仓端到端完成，不悄悄改旧快照。消费适配开始前另建 before 测试需求。

收尾记录应说明：哪些问题已复现、哪些环境不可得、哪些限制已写入能力文档、哪些会阻断下一阶段。没有实测证据的项目保留未勾选。
