# 开发后不确定项：M4-B 外部 ASR 协议与传输

日期：2026-11-04；对应需求：[M4-B before](2026-11-04-m4b-asr-before.md)。

## 已验证

- 标准库 HTTP ASR adapter 可发送已校验的单个音频片段，并将供应商相对毫秒时间加片段偏移映射到源 stream 时间线。
- 已覆盖词级时间、speaker、空结果、响应/请求上限、密钥隔离、无重定向、稳定错误码和不泄漏供应商正文。
- 无真实供应商请求、无本地模型、无 ASR 结果写入 ParseResult/Store；`AsrResponse` 仍是独立的外部结果。

## 仍需人工或真实服务确认

- 尚未选定真实外部 ASR，语言/中文、标点、重叠讲话、噪声、长音频、说话人和词级时间效果都没有标注验收。
- 当前协议是同步单片段，尚未实现异步远端 job、query/cancel、重试/未知计费保护和调用账目关联。
- 尚未定义 FFmpeg 转码、分段窗口/重叠、边界重复去除、多轨选择、字幕合并及“缺段”覆盖计算。
- 服务 usage 只保留输入毫秒和可选 cost；供应商返回 token、货币、税费或未知扣费的映射仍需产品账目契约。

这些项目不能由本地合成 HTTP 响应通过而提前开放 `transcribe` 或视频理解目标。
