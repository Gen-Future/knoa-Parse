# 开发后不确定项：M4-E 音视频覆盖与成本闸门

日期：2026-11-04；对应需求：[M4-E before](2026-11-04-m4e-media-gates-before.md)。

## 已验证

- 无音轨预检、连续/部分/全部失败覆盖、缺段范围和 chunk 重叠冲突均有明确结果；覆盖只按 core 区间计算。
- 已知费用会求和，未发送费用为 null，任一未知费用保持 null，不会把未知账单写成 0。
- 结果是独立 `MediaExecutionSummary`，未修改现有 `ParseResult`、能力清单或产品路由。

## 仍需人工或真实环境确认

- 真实 provider 的 usage 与账单、重试/取消/重复计费关系尚未接入调用账目。
- 真实音频静音、ASR 缺段、分段重复和视觉/字幕缺失尚无标注集；覆盖不等于识别质量。
- `video_understanding` 需要把音轨、字幕、场景、视觉分别纳入产品结果契约，当前只有时间/成本基础。

M4 的真实工具链、服务效果和生产开关保持未开放。
