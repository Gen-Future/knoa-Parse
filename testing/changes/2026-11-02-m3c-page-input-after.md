# 开发后不确定项：M3-C PDF 页图输入与几何映射

日期：2026-11-02；关联 [开发前需求](2026-11-02-m3c-page-input-before.md)、[执行记录](../records/2026-11-02-m3c-page-input.md)、[能力闸门](../../docs/TODO.md)。

## 已验证事实

合成 PDF ParseResult 与固定栅格字节验证了 Source/coverage 绑定、SHA/大小、媒体类型、页集合、artifact 冲突、乱序排序、旋转宽高交换、2% aspect ratio 容差和原结果不可变。模块只生成 `PreparedPage`，不读取文件路径、不渲染、不调用 Provider。当前 9 项自动测试通过；没有真实 PDF 或图像效果验证。

## 不确定项与 TODO

- [ ] **M3C-UNC-01 / P0 / PDF 渲染来源**。需要选定非模型渲染路径并确认许可证、字体、透明度、超大页面和首次运行行为。对至少 3 份去敏 PDF 保存源 SHA、页规格、渲染参数和栅格 SHA；当前函数接受调用方输入，不能证明渲染正确。未完成前不得把任意网络上传直接送外部服务。
- [ ] **M3C-UNC-02 / P0 / 旋转与裁切语义**。真实 PDF 的 MediaBox/CropBox/Rotate 组合可能与合成规格不同。人工逐页检查 full_page_upright 是否包含完整可见页，90/180/270 是否与阅读器一致；裁切页必须明确拒绝或定义新映射，不能靠 aspect ratio 猜测。
- [ ] **M3C-UNC-03 / P1 / 栅格质量与大小**。确认 DPI、抗锯齿、颜色、透明背景、JPEG 质量对外部服务效果和费用的影响；预先定义页图字节/像素上限和超限策略。当前 2% 只校验比例，不是图像质量指标。
- [ ] **M3C-UNC-04 / P0 / 服务几何校准**。外部服务坐标回写仍由 M3-A 做比例转换，当前精度为 estimated。用真实服务对照人工框，验证像素原点、旋转、pt 尺寸和边界误差；未校准前不得标 source_exact。
- [ ] **M3C-UNC-05 / P1 / 大页面资源**。测试超大像素页、错误截断、内存压力和多页批量；确认渲染/读取过程有界、临时文件可清理。当前输入校验本身不解码图像，不能代替运行时资源测试。

## 收尾结论

M3-C 只完成页图输入契约和几何前置校验；真实渲染、OCR 效果、服务费用与产品路由继续由 [docs/TODO.md](../../docs/TODO.md) 阻塞。人工资源不足时可先收集去敏样本和渲染元数据，不能勾选真实效果项目。
