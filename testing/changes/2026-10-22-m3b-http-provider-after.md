# 开发后不确定项：M3-B 通用外部文档服务适配器

日期：2026-10-22；关联 [开发前需求](2026-10-22-m3b-http-provider-before.md)、[执行记录](../records/2026-10-22-m3b-http-provider.md)、[M3-A 约束](../../docs/m3-document-analysis.md)。

## 已验证事实

本地 HTTPServer 合成协议覆盖请求字段、页图 base64/media_type、Bearer 头、HTTPS 默认限制、状态码映射、重定向拒绝、响应大小、JSON/Schema 校验、网络失败与一次调用语义；并联动 M3-A 验证一页成功一页失败为 partial。适配器只返回内部 `PageAnalysis`，不创建 `ParseResult`。未调用真实服务，未测 OCR 识别准确率、服务费用、厂商 SLA、异步任务或真实页图几何。

## TODO / 不确定项

- [ ] **M3B-UNC-01 / P0 / 真实厂商协议**。待选择一个文档分析服务，核对真实 endpoint、认证、请求图片格式、坐标单位、响应字段和模型版本。将协议变更写成独立适配器，不把通用 JSON 猜测直接用于生产。证据：官方文档、固定版本请求/响应、脱敏联调。未完成前不注册 provider。
- [ ] **M3B-UNC-02 / P0 / 真实页图映射**。当前 adapter 接收调用方已准备的 full_page_upright 图。需要验证 PDF 渲染、旋转/裁切/页面尺寸、像素与 pt 的关系及摘要绑定；至少 3 份真实去敏 PDF，逐页标注。未完成前不开放扫描 PDF。
- [ ] **M3B-UNC-03 / P0 / 服务效果**。对中文原生、扫描、混合、多列、表格准备人工标注集，预先定义文字、区域、结构和缺口指标；调用一次固定服务版本并保存差异。供应商 benchmark 不能代替 Knoa Parse 验收，结果达不到门槛时保留 partial/拒绝启用。
- [ ] **M3B-UNC-04 / P0 / 取消与计费**。同步 transport 只保留一次请求和未知计费状态。需验证服务是否支持远端 request ID、查询、取消、幂等，设计页级持久化恢复和重复计费保护。未完成前不把 timeout 当作扣费已停止。
- [ ] **M3B-UNC-05 / P1 / 生产网络边界**。在真实环境验证证书、代理、DNS、重试策略、最大响应、服务错误正文脱敏和 key 不进日志；确认不允许的重定向不会送 key。当前回环 HTTP 仅为测试开关。
- [ ] **M3B-UNC-06 / P1 / 依赖与部署**。确认标准库 transport 能满足代理、证书和连接池需求；若引入 SDK，重新做依赖闭包、许可证和本地模型审计。当前无新增依赖，不能据此承诺生产连接池性能。
- [ ] **M3B-UNC-07 / P1 / 产品合并**。为 document_understanding 定义新契约、原始响应 artifact、ProviderInvocation 持久化、原生/识别 coverage 合并和 UI 展示，再接 worker/API。当前 adapter 只可被显式注入，能力清单仍没有 OCR。

## 收尾结论

M3-B 的通用传输骨架和自动协议测试已完成；真实服务、真实页图、效果、费用、异步恢复和产品路由均是待办。人工资源不足时先按上述优先级积累资料和供应商证据，不用合成 HTTP 测试替代真实能力验收。
