# 开发前测试需求：工作台 review 修复

日期：2026-11-10。范围：修复 V2 桌面溢出、诊断/轮询焦点与会话竞态、日志脱敏和状态展示缺陷。只修改可选工作台、测试与文档，不改变解析层或 HTTP 契约。

## 样本与独立预期

使用隔离数据目录和合成 API 响应：六种任务状态、长文件名/ID、缺失来源、覆盖缺口、派生产物、带引号/空格的合成密钥，以及延迟返回的请求。不读取真实凭据或上传真实资料。

## 验收用例

- [ ] CR-01 / P0：1440×900、1280×800、1024×768 下切换三个主视图和展开诊断；文档宽度不大于视口，长 ID 换行，工具栏不互相覆盖。浏览器截图与 DOM 尺寸为证据。
- [ ] CR-02 / P0：聚焦任务、tab、诊断复制/关闭按钮后触发轮询及结果加载；焦点保持在对应控件，滚动位置保持，关闭后焦点回到当前诊断触发器，Esc 可关闭。tab 与 panel 一一关联。
- [ ] CR-03 / P0：模型测试合成错误、带引号 JSON/Authorization/URL 形式的凭据不进入诊断事件；日志只保留受控字段和稳定错误码，不保存任意响应正文/资料文本。最多 100 条且字段长度有限。
- [ ] CR-04 / P1：重连后保留页面诊断历史，完整刷新页面清空；重连前的延迟结果/来源/上传请求不得写入新会话。重复请求可合并，旧结果不能覆盖新选择。
- [ ] CR-05 / P1：来源查询失败仍可打开任务并显示缺失原因；任务滑出最近 100 项后仍显示并轮询选中任务；不得猜测 worker 心跳。
- [ ] CR-06 / P1：partial/failed/cancelled 不出现绿色成功流程提示；真实目标、覆盖与问题关联和完整产物 ID 可查可复制。配置只读时表单只读，未保存设置切视图不丢失。
