# 开发前测试需求：M4-B 外部 ASR 协议与传输

创建日期：2026-11-04；状态：实现前定义。范围：定义外部 ASR 的供应商无关请求/响应模型和受控同步 JSON transport；不接入本地 Whisper、神经 VAD、说话人模型或真实供应商，不注册音频/视频产品路由。

## 目标与边界

- `core/asr.py` 表达已准备的派生音频片段、源 stream、原始片段范围、词/段时间戳、可选 speaker 和费用/输入时长；片段字节不进入序列化结果。
- Provider 请求中的时间单位固定为毫秒，供应商返回的片段/词时间加片段起点后映射回原音轨；缺段不补写空文本，不把一次成功调用声明为全音频完成。
- `providers/asr/http.py` 只使用标准库 HTTPS/JSON，API key 仅在 header；禁止重定向、URL 凭据和供应商异常原文泄漏。
- 发出前核对派生 artifact role、大小、SHA、媒体类型、片段时长/字节预算；响应严格校验段/词范围、顺序、usage 与结构。
- 这是同步协议基础；异步 job、query/cancel、调用账目和分段去重以后另建阶段。无本地模型回退。

## 验收用例

- [ ] M4B-01 / P0：有效音频片段映射 base64、媒体类型、片段范围、语言、时间戳/diarization 选项和幂等键；不发送 source ID 或密钥 URL。
- [ ] M4B-02 / P0：供应商相对时间加片段偏移后得到原音轨绝对毫秒；词级时间和 speaker 保留；结果按时间排序。
- [ ] M4B-03 / P0：空 segments 保持空结果；越界、反向、空白文本、词超段、非法 usage/重复 JSON 键整包拒绝。
- [ ] M4B-04 / P0：派生 artifact 摘要/大小/媒体类型不符、请求超限在外发前拒绝，服务不被调用。
- [ ] M4B-05 / P0：HTTPS 默认、回环 HTTP 仅显式测试开关；重定向、401/403/408/429/5xx、超时、非法 JSON、过大响应均归一化且不泄密。
- [ ] M4B-06 / P0：能力声明为 `external_service`，支持字级时间/diarization 只代表协议能力，不代表真实服务效果或供应商已启用。
- [ ] M4B-07 / P0：专项、完整回归、静态检查、依赖审计和文档检查通过；依赖增量为 0。

真实 ASR 选型、数据区域、语言/中文效果、计费、异步恢复、分段重叠去重和人工标注验收留在后续阶段。
