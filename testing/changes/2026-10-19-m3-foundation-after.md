# 开发后不确定项：M3 外部文档能力基础

日期：2026-10-19；范围：M3-A 内部同步单页协议、页级编排、上下文及预算。关联 [开发前需求](2026-10-19-m3-foundation-before.md)、[执行记录](../records/2026-10-19-m3-foundation.md)、[实现边界](../../docs/m3-document-analysis.md)。

## 已验证与适用范围

合成响应验证 source/artifact 绑定、整批预检、坐标换算、上下文、累计预算、取消/超时、异常脱敏、无重试、mock 防误用及原生结果独立。完整 Windows Python 回归 108 项通过，之后新增的累计预算/输入隔离测试包含在本模块 20 项复验中；该 20 项在完整/无文档基础环境均通过。未做真实服务调用，不使用历史模型账户结果充当本轮验证。

## 必须另行验证的部分

- [ ] **M3-UNC-01 / P0 / 真实页图及几何映射**。当前调用方声明尺寸/正向全页关系，没有渲染器和图片解码验证。步骤：后续准备至少 3 份含旋转、裁切、不同页面尺寸的真实 PDF，逐页渲染；在原件预标至少 5 个框，比较像素尺寸、旋转及 pt 映射。预期：摘要绑定正确，所有测试框对应原件同一内容；无法转换的几何类型先拒绝。证据：输入摘要、渲染参数、对照图和报告。处置：阻断公共输入接入，下一轮页图准备任务解决；负责人待分配。
- [ ] **M3-UNC-02 / P1 / OCR/版面真实效果**。目前文字全部人工预写，不能证明识别能力。步骤：选服务后对原生中文、扫描、混合、多列/表格至少各 3 份合法去敏文件预标文字和区域，先明确识别/结构目标再调用；对照遗漏、误识别、位置、空页与阅读顺序。预期：达到该服务接入前定义的指标，失败如实保留；不能继承开源或供应商分数。证据：服务版本、标注、逐项差异、实际调用和成本。处置：阻断 document_understanding 开放；负责人待分配。
- [ ] **M3-UNC-03 / P0 / 真实取消与计费状态**。同步调用只能前后检查，timeout_seconds 是适配器必须履行的约束，非 OS 强杀机制。步骤：接入适配器后用可控延迟/断连服务测试，记录本地结束、远端请求状态、是否继续扣费；如服务支持 query/cancel，验证恢复查询。预期：不隐式重发，不丢调用账目，不把未知账单写 0。证据：脱敏 trace、远端 ID、请求计数和延迟。处置：当前明确限制，异步/恢复另建工程；负责人待分配。
- [ ] **M3-UNC-04 / P0 / 持久化和产品合并**。本轮报告不注册页图/原始响应到 Store，不修复 native coverage，也不去重原生页眉/OCR。步骤：产品接入前写新版契约测试，再用同页重复文字、部分页失败和崩溃样本检查发布事务、来源/上下文绑定、原生与识别并置、缺口合并及恢复。预期：原证据不覆盖，重复来源可解释，失败不变 completed；掉线后无盲目重复计费。证据：新契约、持久化产物和恢复记录。处置：阻断产品任务目标开放；负责人待分配。
- [ ] **M3-UNC-05 / P1 / 真实响应与资料发送范围**。内部返回对象仅验证标准结构，供应商原始响应限额和脱敏尚待真实适配器实现。步骤：用合成 key/受控服务发送错误体、超大体、重定向、非法区域和含密钥诱饵的错误；检查日志及报告，同时核对发送的页图/同页上下文范围。预期：不转发凭据、不外发其他页、不回显异常原文，响应读取有界。证据：脱敏请求、字节上限及报告。处置：阻断真实适配器准入；负责人待分配。
- [ ] **M3-UNC-06 / P1 / 用量及费用预算**。只有调用数/字节/时限/输出预算，token 用量未知保持 null，cost 始终 null。步骤：选服务后事先定义货币上限和预估策略；对成功、失败、取消、异步未知和重复请求核对平台账单。预期：不能仅用 tokens 相加声称成本受控；服务无法支持严格费用上限时明示。证据：计价配置版本、脱敏账单与账目。处置：在真实付费任务开放前解决；负责人待分配。
- [ ] **M3-UNC-07 / P1 / 跨平台与大响应**。本轮仅 Windows、两个现有虚拟环境；没有实际 Linux/macOS 和真实大页图压力运行。步骤：在可获得平台跑相同测试，再用接近预算的真实页图检查峰值内存、总耗时与取消。预期：有界资源、相同语义、无后代进程或本地模型；缺少平台记阻塞。处置：保留平台限制，不扩大发布承诺；负责人待分配。

## 阶段结论

M3-A 编排基础可在离线实验中使用；真实服务与产品接入仍受上述条目限制。现有 native_extract 及工作台不依赖它。没有开放新后缀/目标，没有修改主仓快照，没有新增运行依赖或使用真实账户。M2 真实中文资料人工验收仍未完成。
