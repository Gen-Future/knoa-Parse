# 开发前测试需求：M3 外部文档能力基础

创建日期：2026-10-19；状态：实现前定义。范围：core 文档分析协议及 enrichment 页级编排；不接真实供应商、不开放新 API/任务目标，不改变 native_extract、现有 Schema 或主仓快照。负责人：本轮实现者。

## 目标与输入边界

将已经准备好的完整、正向页图送给显式注入的文档分析 Provider，合并文字及页坐标，保留原生结果、上下文引用和调用账目。页图与原件的映射必须由调用方提供，当前只接受同尺寸比例的全页图，不支持裁切或旋转变换。页图渲染、真实服务选择、异步远端恢复和任务存储集成本轮不做。

上下文使用已有原生块 ID，按同页选择，不按重复文字猜测归属。Provider 描述区别 mock 与 external_service；mock 仅允许显式 dry_run，真实模式遇 mock 必须在发送前失败。生成说明不能冒充 OCR。未知费用/用量保持 null，不用 0 充当未知。

## 样本及独立预期

使用测试内合成 Source/Artifact/原生页块、固定字节页图与预写 Provider 响应。页尺寸 600×800 pt、1200×1600 px，normalized/top_left 与 px/bottom_left 的已知框均应映射到同一 pt/top_left 区域。页 1 成功、页 2 失败时保留页 1 并显式页 2 缺口，输入页可以乱序，输出按源页排序。上下文包含同页/异页/多页块与重复文字。

## 验收用例

- [ ] M3-01 / P0：未配置、mock 冒充真实、服务不支持输入、全量页数/字节预算不足，在任何调用之前失败；计数为 0。
- [ ] M3-02 / P0：校验 Source 绑定、页图 SHA/大小/媒体类型、页 ID 重复/越界、空页图、非正向全页映射；异常不发送。不同 source/artifact 不能混用。
- [ ] M3-03 / P0：normalized 和 px（含 bottom_left）归一化到已知 pt/top_left；缺失定位、越界框、非有限值不伪造位置。
- [ ] M3-04 / P0：识别文字 acquisition=ocr，模型说明 acquisition=inferred 且有输入上下文引用；原生块和覆盖状态不被覆盖。新块 ID 与已有 ID 不冲突。
- [ ] M3-05 / P1：页响应数量/身份正确；乱序输入输出按页号归并；空白页需服务明确声明 blank，不允许空输出默认成功。
- [ ] M3-06 / P0：同页上下文按原生顺序截断，保留实际传出的 block IDs、截断标记，字符与引用数均有上限；不发送异页或多页归属不明块。
- [ ] M3-07 / P0：页 2 Provider 临时错误后不自动重试，后续页可继续；响应/异常内不可信消息不得直接写账目；调用次数可证明。
- [ ] M3-08 / P0：调用前取消为 0 次发送；调用后取消保留远端可能计费记录并丢弃该次内容，后续页不发送。不承诺终止同步远端计费。
- [ ] M3-09 / P0：调用次数、总时限、总块数/字符数受预算约束；超限响应不发布，不改写为成功；未知用量/费用保持 null，显式零用量可以保留。
- [ ] M3-10 / P1：一页成功一页失败返回 partial；全部失败/取消无内容不能报告 completed；dry_run 带明确标志且无法转为现有 ParseResult 的产品目标。
- [ ] M3-11 / P1：报告 JSON 不包含页图 bytes 或凭据，只保留引用/摘要、标准结果和脱敏调用账目；有可独立执行的离线演示报告。
- [ ] M3-12 / P0：全量现有测试、文档/契约/导入边界、依赖审计通过；uv.lock 无变更，不引入模型/新运行依赖；运行能力仍仅 native_extract。

自动验证：新建独立 unittest 覆盖上述合成分支；离线演示脚本输出带 dry_run 的报告。人工验证：真实服务效果、页图映射、脱敏与取消的实际环境行为在开发后清单单列。未配置供应商不得擅自消耗账户额度。

通过条件：所有适用自动分支通过；文档清楚区分内部基础与产品可用服务；未实现目标不启用。开发后记录：[M3 不确定项](2026-10-19-m3-foundation-after.md)（工作结束时补建）。
