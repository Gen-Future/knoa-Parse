# 开发前测试需求：M4-C 场景候选与时间关联

创建日期：2026-11-04；状态：实现前定义。范围：在不加载模型、不负责解码的前提下，接收外部/注入检测器给出的实际帧 PTS 与变化分数，生成场景候选、抽样覆盖和音频/字幕/转录时间关联；不安装 PySceneDetect、不执行真实视频解码、不开放 `video_understanding`。

## 目标与边界

- `core/scenes.py` 表达时间范围、帧样本、场景、抽样覆盖和可关联证据；所有时间为原视频毫秒左闭右开。
- `processors/media/scenes.py` 只做阈值、最短场景、实际 PTS 和区间并集计算；像素差异检测由后续注入的 PySceneDetect 或其他非模型 detector 提供，不在本阶段复制解码/检测器实现。
- 场景边界只能来自样本 PTS 与请求时间范围；样本间没有覆盖时保留 gap，不能因为帧率或帧号推断已观察。
- 音频、字幕、转录证据只按时间区间相交建立链接；无重叠不建立链接，缺段不补写文本或视觉事实。

## 验收用例

- [ ] M4C-01 / P0：实际 VFR PTS 和变化分数按阈值生成场景；短于 `min_scene_ms` 的候选被抑制，边界保留真实毫秒。
- [ ] M4C-02 / P0：样本按 PTS/帧号有序且唯一；样本超出请求区间、重复帧或非法区间拒绝。
- [ ] M4C-03 / P0：抽样覆盖以帧 duration 区间并集计算；空样本、长间隔和边界间隙显式可见，不报告全覆盖。
- [ ] M4C-04 / P0：每个场景保留帧范围和 sampled_ms；没有样本的场景仍是未观察区间，不伪造帧。
- [ ] M4C-05 / P0：转录/字幕/音频区间仅在相交时关联；重复 ID、零长度和跨时间线结果拒绝。
- [ ] M4C-06 / P0：专项、静态检查、依赖审计和文档检查通过；不新增本地模型/视频解码依赖。

真实 PySceneDetect 版本、Detector 参数、实际视频抽样、短镜头/黑帧/淡入淡出、VFR 与音轨时间校准留在后续 M4 产品阶段。
