# 解析层验收计划

状态：保留全家族验收设计；文本/JSON 和初始原生文档已有合成回归，其他家族仍待实现。当前证据见 baselines/2026-10-15-documents.json。

| 家族/能力 | 最小样例 | 必须验证的结果 |
| --- | --- | --- |
| text | 中文、emoji、BOM、不同换行、代码块 | 原文 code point 偏移正确；解码/清洗不破坏映射 |
| structured | 嵌套 JSON、坏行 JSONL、XML/YAML | 类型和节点路径正确；坏记录有明确状态；不执行对象/外部实体 |
| pdf | 原生、扫描、混合、旋转、多列、有表格 | 页级路由、阅读顺序、表格/区域；有文本页眉不掩盖扫描正文 |
| document | 段落+表格+图片+页眉脚注+修订 | 保留支持内容及缺口；不把渲染页冒充原始固定页 |
| presentation | 文本+图表+分组形状+备注+图片页 | slide/shape 定位，正文/备注分离；图表数据与视觉描述有区别 |
| spreadsheet | 合并/隐藏、公式无缓存、大表、CSV 转义 | sheet/范围/类型不丢；缓存缺失不变 0；不计算公式 |
| image | EXIF 旋转、多页 TIFF、截图和自然场景 | 坐标映射、帧顺序、OCR 与描述的来源标记 |
| audio | 超长分段、静音、跨段词语、多个说话人 | 原时间线、重复边界、缺段状态；不伪造说话人一致性 |
| video | 无音轨、有字幕、可变帧率、短镜头、画面与声音矛盾 | 音/字幕/图三支路对齐；原始 PTS；声明采样覆盖限制 |
| web | 静态页、长表格、依赖 JS 的页面 | 固定快照来源、正文损失说明；未采集动态内容不能报完整 |
| ebook | spine 与文件名顺序不一致、章节图片 | 阅读顺序、资源路径；不伪造固定页码 |
| email | multipart、内联图片、嵌套邮件、附件 | MIME 层级、正文去重、附件与消息关联 |
| archive | 嵌套、坏条目、同名条目、越界路径、高压缩比 | 单项错误聚合、完整来源链、资源限制与路径隔离 |
| Provider | 合成 429/超时/永久失败、pending/轮询、重复请求 | 有界重试、恢复、不盲目重复计费、时间/坐标单位归一 |
| 无本地模型 | 无网络、空模型缓存、仅非模型依赖的执行环境 | 不下载权重、不调用本地推理；缺少外部能力时明确报告 |
| 主仓兼容 | 新版本生产结果与消费导入 | 版本协商、证据定位、来源授权与完整性一致 |

## 评测记录

每次记录：样例 ID/许可/摘要、解析器与工具版本、处理配置、契约版本、Provider/model/区域、目标模式、结构正确性、定位正确性、遗漏/重复、外部调用量、时延和资源用量。未知成本/指标留未知，不填 0 代替。

先建立少量人工核对的合成 golden 样例，再引入许可明确的真实资料。布局/识别效果由人工标注或独立评估比较；供应商返回了文本不等于识别正确。阈值由第一轮基线结果决定，本轮不预设任意通过率。

## 依赖采用实验

优先比较成熟项目的原始输出与 Knoa 适配输出，确认复用后的能力和来源信息没有静默损失；底层库作为必要对照或补充，不作为默认重建路径。

- Docling：在冻结版本下验证精简依赖的实际导入链，比较 Office 与原生 PDF 转换前后的正文、表格、图片、顺序、定位和完成状态。复杂 PDF 的外部增强单独测试。
- 上下文增强：RAG-Anything 仅作设计参考，不预设源码迁移。验证 Knoa 上下文 block 引用、优先级、实际预算与截断记录，异常不返回空成功；mock 与真实服务效果分开验收。
- 音视频：直接验证 PySceneDetect 场景候选与媒体实际 PTS 的关系，覆盖可变帧率、空音轨、ASR 缺段和抽帧覆盖；不安装 RAG-Anything 视频依赖或本地 Whisper/VAD。
- 归属与升级：记录固定版本、源码改动及预期差异，升级引擎时复跑同批样例；保留上游结果 artifact 以核对映射损失。

只有使用同一批资料、同一目标与同一指标的结果才能用于选型。项目自报 benchmark 不直接替代实验，替换上游模型后的效果不继承原项目成绩。采用门槛见 [实现方案](../docs/implementation-plan.md)。

## 依赖与成本基线

分别记录 base/documents/media/web-maintext/provider-specific 的锁定依赖、安装体积、冷启动、峰值 RSS、临时空间和外部调用。未安装的可选组不能成为基础启动的隐式依赖。首版只有一个通用文档引擎；新增模块必须提交独特收益与成本增量。首轮分组与运行观察见 [文档基线](baselines/2026-10-15-documents.json)，不等于完整性能基准。

Excel 增加公式无缓存、纯公式区域、百分比/日期格式、隐藏行列、同名内容和区域外单元格样例；来源映射不唯一时不得猜测合并。精确定位到上游 JSON 不等于精确定位到原 DOCX/PPT，需分别记录并验收。
