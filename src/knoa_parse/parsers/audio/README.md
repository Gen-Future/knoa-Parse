# 音频解析

状态：planned；M4-A/M4-D 完成可注入的 ffprobe 探测与受限分段基础，音频解析仍未实现/启用。建议优先级：P1。属于资料家族，后续可以是同一个进程中的模块，不要求独立服务。

## 范围

首批候选：`.wav`、`.mp3`、`.m4a`、`.flac`、`.ogg`。后续候选：`.aac`、`.opus`。这些是规划，不是支持声明。

## 专用流程

探测音轨 → 非模型转码/分段 → 外部 ASR → 去除分段重复 → 原音轨时间对齐。

## 定位与输出

流 ID、原音轨毫秒范围、分段偏移；说话人标识作用域。

现有 v0.1.0-draft.1 不一定能表达本家族全部结构，按 [结果模型](../../../../docs/result-model.md) 升级契约后再开放相应能力。

## 依赖边界

只依赖 core 定义的接口，apps 注入成熟转换/内容增强适配、非模型工具和外部 Provider；仅按当前家族需要使用。非模型工具分组：media。按目标可能需要的外部能力：asr；不是每个文件都全部调用。不得导入其他家族内部代码；复合资料走 core 子任务分派。

## 复用候选

采用 FFmpeg/ffprobe 做流探测与受控分段，识别交给 AsrProvider；时间映射、分段去重和失败语义由 Knoa 维护。不安装 RAG-Anything、Whisper、神经 VAD 或 MoviePy。 具体边界见 [横向选型](../../../../docs/research/2026-10-15-module-selection.md) 和 [实现方案](../../../../docs/implementation-plan.md)；当前未安装或启用。

## 实现前验收

静音、多语言、重叠讲话、长音频、部分片段失败；神经 VAD 和说话人分离也不得本地运行。

共同规则见 [处理流程](../../../../docs/pipelines.md) 与 [评测计划](../../../../evals/README.md)。
