# 文本解析

状态：部分实现；当前只启用 .txt（UTF-8），其他后缀未启用。建议优先级：P0。属于资料家族，后续可以是同一个进程中的模块，不要求独立服务。

## 范围

首批候选：`.txt`、`.md`、`.log`、`.rst`、`.py`、`.js`、`.java`。后续候选：`.rmd`、`.qmd`。这些是规划，不是支持声明。

## 专用流程

编码/BOM 探测 → 解码 → 结构读取 → 原文位置映射 → 内容块。

## 定位与输出

字符偏移、行号、编码；清洗前后映射。

现有 v0.1.0-draft.1 不一定能表达本家族全部结构，按 [结果模型](../../../../docs/result-model.md) 升级契约后再开放相应能力。

## 依赖边界

只依赖 core 定义的接口，apps 注入成熟转换/内容增强适配、非模型工具和外部 Provider；仅按当前家族需要使用。非模型工具分组：markup。本家族自身默认不调用模型；子资料按其家族能力规划。不得导入其他家族内部代码；复合资料走 core 子任务分派。

## 复用候选

Markdown 验证已选 Docling backend 的结构与来源；纯文本使用成熟解码与语法能力。上下文选择按 Knoa 引用契约实现，RAG-Anything 仅作设计参考，不额外安装 RAG 框架。 具体边界见 [横向选型](../../../../docs/research/2026-10-15-module-selection.md) 和 [实现方案](../../../../docs/implementation-plan.md)；当前未安装或启用。

## 实现前验收

混合换行、中文及 emoji、BOM、未知编码、超长行、代码块；不执行文本中的程序。

共同规则见 [处理流程](../../../../docs/pipelines.md) 与 [评测计划](../../../../evals/README.md)。
