# Excel 与表格解析

状态：初始原生路径已实现；需安装并通过 documents 组审计，后续格式和模型目标仍未启用。建议优先级：P0。属于资料家族，后续可以是同一个进程中的模块，不要求独立服务。

## 范围

首批候选：`.xlsx`、`.csv`、`.tsv`。后续候选：`.xls`、`.xlsb`、`.ods`。这些是规划，不是支持声明。

## 专用流程

工作簿/分隔符识别 → sheet/单元格/范围 → 类型/公式/缓存值 → 区域化输出；图片按需分派。

## 定位与输出

工作表 ID/名称、A1 范围、合并单元格、隐藏状态；CSV 记录/字段位置。

现有 v0.1.0-draft.1 不一定能表达本家族全部结构，按 [结果模型](../../../../docs/result-model.md) 升级契约后再开放相应能力。

## 依赖边界

只依赖 core 定义的接口，apps 注入成熟转换/内容增强适配、非模型工具和外部 Provider；仅按当前家族需要使用。非模型工具分组：office。按目标可能需要的外部能力：ocr、vision；不是每个文件都全部调用。不得导入其他家族内部代码；复合资料走 core 子任务分派。

## 复用候选

采用 Docling 的区域/表格组织，另以现有 openpyxl 依赖读取工作表/A1、公式、缓存、原始值/类型、数字格式与合并/隐藏字段。上游 data_only 路径不能替代原始语义；缺缓存的公式也必须保留。补充层不重新实现表格分区或公式计算。CSV/TSV 使用成熟语法读取器。 具体边界见 [横向选型](../../../../docs/research/2026-10-15-module-selection.md) 和 [实现方案](../../../../docs/implementation-plan.md)；当前原生路径已有合成资料及任务链验收。

## 实现前验收

公式缓存缺失、日期序列、合并/隐藏、巨表、转义分隔符；不执行宏、外链或公式。

共同规则见 [处理流程](../../../../docs/pipelines.md) 与 [评测计划](../../../../evals/README.md)。
