# 电子书解析

状态：planned；未实现、未启用。建议优先级：P2。属于资料家族，后续可以是同一个进程中的模块，不要求独立服务。

## 范围

首批候选：`.epub`。后续候选：`.mobi`、`.azw3`。这些是规划，不是支持声明。

## 专用流程

读取 manifest/spine → 按章节顺序读取 XHTML → 图片等子任务 → 章节定位。

## 定位与输出

书内资源路径、spine 顺序、元素锚点；不虚构固定页数。

现有 v0.1.0-draft.1 不一定能表达本家族全部结构，按 [结果模型](../../../../docs/result-model.md) 升级契约后再开放相应能力。

## 依赖边界

只依赖 core 定义的接口，apps 注入成熟转换/内容增强适配、非模型工具和外部 Provider；仅按当前家族需要使用。非模型工具分组：containers、markup。按目标可能需要的外部能力：ocr、vision；不是每个文件都全部调用。不得导入其他家族内部代码；复合资料走 core 子任务分派。

## 复用候选

EbookLib/Calibre 为待许可与部署评估的候选；成熟 ZIP/XML/HTML 工具处理基础结构。依据与取舍见 [调研](../../../../docs/research/2026-10-14-parser-landscape.md)，尚未安装或锁定运行时依赖。

## 实现前验收

目录顺序不等于文件顺序、嵌图、DRM、坏资源；不引入整套重型转换器作为首批必需依赖。

共同规则见 [处理流程](../../../../docs/pipelines.md) 与 [评测计划](../../../../evals/README.md)。
