# 压缩包与资料集解析

状态：planned；未实现、未启用。建议优先级：P2。属于资料家族，后续可以是同一个进程中的模块，不要求独立服务。

## 范围

首批候选：`.zip`、`.tar`、`.tar.gz`、`.tgz`。后续候选：`.7z`、`.rar`。这些是规划，不是支持声明。

## 专用流程

限额检查/受限解包 → 子项探测 → core 分派 → 聚合结果/失败。

## 定位与输出

容器链、条目路径、每个子资料的来源版本/摘要。

现有 v0.1.0-draft.1 不一定能表达本家族全部结构，按 [结果模型](../../../../docs/result-model.md) 升级契约后再开放相应能力。

## 依赖边界

只依赖 core 定义的接口，apps 注入成熟转换/内容增强适配、非模型工具和外部 Provider；仅按当前家族需要使用。非模型工具分组：containers。本家族自身默认不调用模型；子资料按其家族能力规划。不得导入其他家族内部代码；复合资料走 core 子任务分派。

## 复用候选

语言 ZIP/TAR 库；其他格式使用经评估的成熟工具，不自研解压缩算法。依据与取舍见 [调研](../../../../docs/research/2026-10-14-parser-landscape.md)，尚未安装或锁定运行时依赖。

## 实现前验收

路径穿越、符号链接、压缩炸弹、嵌套过深、重复文件名；OOXML/EPUB 专有探测优先。

共同规则见 [处理流程](../../../../docs/pipelines.md) 与 [评测计划](../../../../evals/README.md)。
