# ADR 0005：解析优先的可选观测工作台

2026-10-19 更新：按用户要求，当前单用户 Demo 默认免鉴权，页面自动加载，移除 token 输入及登录弹窗。下文原有“保留鉴权”和“页面内 token”记录为初始设计，已由本更新取代；当前行为见 [模型与服务配置](../model-services.md)。

- 日期：2026-10-19
- 状态：采用，依据用户明确提出的前端与可观测性任务。
- 补充：原实现方案“不建设独立解析 UI”的范围约束，现允许一个可移除的观测入口；解析优先和原有依赖边界继续有效。

## 决策

1. 工作台位于 apps/console，只消费 HTTP API。核心证据契约、解析器、引擎、Provider、worker 不依赖 UI 类型、显示顺序或页面状态。
2. 使用无构建的静态 HTML/CSS/ES modules；不为辅助界面增加 Node/npm 运行依赖、前端服务、数据库、队列、模型或 CDN。Python 依赖锁保持不变。
3. 独立 console factory 把原 API 挂载到 /api，静态页面使用同源请求，保留原鉴权，不放宽 CORS。原 API factory 和 CLI/worker 的运行方式不变。
4. 为所有调用方补充通用只读接口 GET /v1/jobs?limit=50（上限 100，最近创建排序）与 GET /v1/sources/{id}。前者使用有界查询与排序索引；不领取租约、不执行解析、不回写任务。响应不含租约 token、服务器路径和幂等键。
5. 初始可观测范围仅为后端确实提供的状态、创建时间、来源元数据、产物、覆盖与问题。未上报的阶段、耗时、百分比、费用、心跳显示为未知或不展示，不为美观改写 completed/partial/failed。
6. 上传及取消完全使用原有 API/worker；UI 不在 Web 请求内执行解析、不自动重试创建任务，也不添加隐式模型回退。显示截断仅影响浏览器 DOM，不裁剪原始证据与可下载产物。
7. token 在当前页面内存中；源码、静态资源和浏览器持久存储不含凭据。内容按不可信文本处理，不把原件中的 HTML/SVG、脚本或公式直接执行。
8. 视觉采用暖白、墨绿、低噪声边框、排版留白与并排证据检查；桌面双栏、窄屏上下布局。支持可见焦点、减弱动画和键盘搜索，不引入图表大屏或无依据的运营指标。
9. 工作台 V2 继续沿用三主视图，并在任务 Inspector 内增加只读诊断抽屉。抽屉只使用现有任务、来源、结果、coverage、issues、artifact、capabilities 和模型设置字段，另记录最多 100 条当前页面的同步事件；不增加后端诊断 API，不持久化事件，不显示估算的阶段、耗时、费用或心跳。
10. V2 的视觉验收以桌面 1440、1280 和 1024 宽度为准，窄屏只保持既有基本可用。设计令牌、任务列表语义、tab/tabpanel、dialog、live region 和焦点回收属于前端实现约束，不改变解析主线依赖。

## 验收与后续

真实合成任务覆盖完成/排队/部分/失败状态；验证连接失败、状态筛选、搜索、任务定位、上传/worker/结果、取消、鉴权产物和多尺寸布局。原解析回归保持通过。

前端逻辑测试可单独用 `node --test tests/console_model.test.mjs` 运行，Python 主测试不要求 Node。完整发布仍需各平台回归；本地控制台不是生产多租户管理平台。
